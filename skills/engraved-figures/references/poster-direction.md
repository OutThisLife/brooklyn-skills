# Poster and redaction direction

Use when the deliverable is a cyclic research poster or redacted document plate. There is **no bundled poster image** in this skill — describe composition from the request and any reference the user supplies privately.

## Visual qualities

- Substantial scientific figures distributed around a cyclic composition, not one hero network with tiny icons.
- Quiet serif hierarchy; lower-column density for secondary diagrams.
- Sparse opaque blackouts when redaction is requested — bars over lettering, not white text on black.

## Prompt scaffold

> Create a scientific technical plate about [subject]. Clean white paper, black and neutral gray ink, fine engraved wireframes, stippled points, serif typography, hairline rules. [List distinct figures, positions and relationships.] [Exact copy and labels.] All numerical plots must use supplied data; abstract geometry is schematic. No icons, rounded cards, glossy 3D shading, decorative gradients, stamps, document codes or aged-paper dirt. Preserve readable labels at the intended output size.

If redactions are requested, enumerate the exact labels or names that must be hidden. Specify that bars conceal the letters with no white text over them.

## Revision lessons

- “More figures” means more substantial scientific art, not additional boxes or labels.
- “Old-school” is monochrome linework, stippling and typography — not sepia, stains or stamps.
- Partial redaction must obscure the chosen portion; a strike-through on readable text is not enough when names must never appear.

For separate figure exports, retain the approved perspective and silhouette. Keep the full approved composition alongside individual assets when the user requests both.
